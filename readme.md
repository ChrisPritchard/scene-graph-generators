# Scene Graph Generators

This exposes an attribute, `Generators.SceneGraph`, with a single property sceneName.

To use, first reference this project in the target project:

```xml
    <ProjectReference Include="..\SceneGraphGenerators\SceneGraphGenerators.csproj" 
                      OutputItemType="Analyzer" 
                      ReferenceOutputAssembly="false" />
```

And ensure all .tscn files are loaded in for parsing:

```xml
<ItemGroup>
    <AdditionalFiles Include="**/*.tscn" />
</ItemGroup>
```

You can add this to see the files generated (probably in `.godot/mono/temp/debug/GeneratedFiles`):

```xml
<PropertyGroup>
    <EmitCompilerGeneratedFiles>true</EmitCompilerGeneratedFiles>
    <CompilerGeneratedFilesOutputPath>GeneratedFiles</CompilerGeneratedFilesOutputPath>
</PropertyGroup>
```

Add this attribute to a class with the name of the scene, e.g.

```c#
[Generators.SceneGraph("card")]
public partial class Card : Control
{
    // ...
```

It will generate data like the below for every uniquely named node in your scene:

```c#
// <auto-generated/>
public partial class Card
{
    private BorderedTexture _back;

    private BorderedTexture back
    {
        get => _back ??= GetNode<BorderedTexture>("%Back");
    }

    // ..
```
